# Politique de confidentialité de CODJIA

*Dernière mise à jour : 24 novembre 2026. Éditeur : Mensan Moréno CODJIA (Ouagadougou, Burkina Faso), via le dépôt GitHub Mensan2024/codjia.*

**En résumé : CODJIA ne collecte, ne transmet et ne vend aucune donnée.**

- **Pas d'accès à Internet.** L'application ne déclare pas la permission Internet. Elle ne peut techniquement rien envoyer.
- **Pas de compte, pas de publicité, pas de mesure d'audience, pas de traceur.**
- **Vos textes** restent dans l'application, sur votre téléphone. Ils servent uniquement à fabriquer la vidéo.
- **Vos musiques importées** sont lues à partir du fichier que vous choisissez dans le sélecteur d'Android. L'application n'accède à aucun autre fichier.
- **Vos vidéos** sont enregistrées dans votre Galerie (dossier *Movies/CODJIA*) uniquement quand vous le demandez. Les fichiers de travail sont effacés après chaque export.
- **Sauvegardes.** Les sauvegardes automatiques dans le cloud et les transferts vers un autre appareil sont désactivés pour l'application.
- **Partage.** Quand vous utilisez le bouton Partager, la vidéo est confiée à l'application que vous choisissez, selon les règles de cette application.

**Supprimer vos données.** Désinstaller l'application efface tout ce qu'elle a conservé. Les vidéos que vous avez enregistrées dans la Galerie restent à vous : supprimez-les depuis la Galerie si vous le souhaitez.

**Enfants.** L'application ne collecte aucune donnée, y compris celles des mineurs.

**Changements.** Toute évolution de cette politique sera publiée dans ce fichier, avec sa date. Une fonction en ligne facultative pourrait apparaître plus tard (génération par IA). Elle serait désactivée par défaut et décrite ici avant sa sortie.

**Contact.** Ouvrez un ticket sur le dépôt GitHub. Pour une question de sécurité, utilisez le signalement privé (voir SECURITY.md).
